Informativa sulla privacy — Social Dashboard

Ultimo aggiornamento: 3 agosto 2026.

Social Dashboard è un'applicazione desktop che mostra in un'unica finestra le statistiche dei tuoi account YouTube, Instagram, TikTok e X. Questa pagina spiega quali dati vengono trattati e come.

Dove vivono i tuoi dati

Tutti i dati che l'app raccoglie — token di accesso, statistiche, cronologia dei contenuti — restano esclusivamente sul tuo computer, in un database SQLite locale accanto all'eseguibile. Non esiste un server di Social Dashboard che riceve o conserva questi dati: l'app parla direttamente con le API ufficiali di YouTube, Instagram, TikTok e X usando le tue credenziali.

Cosa viene richiesto a ciascuna piattaforma

Quando colleghi un account, l'app richiede solo autorizzazioni in sola lettura sulle statistiche pubbliche del tuo profilo (es. numero di iscritti/follower, visualizzazioni, elenco dei contenuti pubblicati). L'app non pubblica, modifica o elimina nulla per tuo conto.

L'unica funzione che invia dati all'esterno

Il pulsante facoltativo "Analizza" invia lo snapshot delle statistiche già raccolte a un servizio di intelligenza artificiale per generare un riepilogo testuale, solo quando lo premi tu esplicitamente. Nessun altro dato lascia il tuo computer in nessun altro momento.

Come cancellare i tuoi dati

Puoi scollegare un account in qualsiasi momento dalla schermata "Collega account": il token corrispondente viene eliminato subito dal database locale. Per cancellare tutto, basta eliminare il file cache.db nella cartella dell'applicazione o disinstallare l'app.

Revoca dell'accesso dalla piattaforma

Puoi revocare l'accesso di Social Dashboard ai tuoi account anche direttamente dalle impostazioni di sicurezza di YouTube (Google), Instagram (Meta), TikTok o X, in qualsiasi momento.
